# Infinite Side-Scroller 2D

Mon projet Infinite Side-Scroller 2D est un petit jeu vidéo dont le but est de sauter sur les plateformes apparentes et de tenir le plus longtemps possible pour amasser le meilleur score possible. Il est développé avec Unity.

## Fonctionnalités

- **Lancer une partie** : Bouton sur la page d'accueil pour lancer une partie du jeu
- **Sauter et jouer** : Dans le jeu, vous ne pouvez que faire sauter votre personnage avec n'importe quel touche du clavier.
- **Score** : Un système de score est intégré : +1 à chaque fois qu'une plateforme apparaît.
- **Relancer une partie** : Possibilité de relancer une partie en cas d'échec (vous perdez si vous tombez).
  

## Installation

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/Titinite/Infinite-Side-Scroller-2D.git
   ```
2. Lancer Unity Hub
3. Ouvrir le projet
4. Lancer la scène "Menu"


## Structure du Projet

- **Assets/Prefabs** : Les préfabs du projet (les objets réutilisables, une sorte de template)
- **Assets/Scenes** : Les différentes scènes du jeu
- **Assets/Scripts** : Tous la logique du jeu, fichiers en C#, code principal


## Technologies

- **Unity Engine** : Création du jeu vidéo
- **C#** : Langage de programmation du jeu vidéo et de ses scripts
